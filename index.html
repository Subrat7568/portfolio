Projects

What I've built

College Placement Data Analysis

Python · Data Cleaning · EDA · HTML Dashboard
Problem
A placement dataset of 9,000 students had hidden quality issues, and it wasn't clear whether branch, college tier or skills actually shaped placement outcomes.
Approach
Audited the raw data for duplicates, missing values and formatting problems, then cleaned it with documented decisions (unplaced students' salary set to missing, resume scores capped at 100, branch names standardised). Ran the analysis in Python scripts and built an interactive HTML dashboard with tooltips and a light/dark theme toggle.
Outcome
Found that branch barely affects outcomes, while college tier does: 93.8% placement rate for Tier 1 versus 76.0% for Tier 3. Also flagged that the data looks simulated, so absolute salary figures should be read as directional.
